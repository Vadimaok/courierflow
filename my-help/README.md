# My help

Самостоятельное iPhone-first PWA-приложение календаря смен, расположенное в `my-help/` и развёртываемое по адресу:

`https://vadimaok.github.io/courierflow/my-help/`

## Первая версия

- Месячный календарь с цветными типами дней.
- Добавление выходного, отработанного дня, больничного, ночной смены и отпуска.
- Шаблон циклического графика (рабочие дни / отдых).
- Отчёты за выбранный месяц: часы, смены, выходные, больничные и расчётный доход.
- Почасовая ставка.
- Локальное сохранение на устройстве и экспорт/импорт JSON.
- PWA manifest, iOS standalone режим и базовый офлайн-кэш.

## Ограничения MVP

Данные пока хранятся в localStorage конкретного браузера. Облачная синхронизация, аккаунты, уведомления, экспорт PDF/ICS и расширенная настройка пользовательских шаблонов будут отдельными следующими этапами. Не вводите реальные финансовые или кадровые данные до появления резервного копирования и облачной синхронизации.
